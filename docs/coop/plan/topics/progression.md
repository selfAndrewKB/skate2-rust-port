# Progression: one career on every console (M2)

**Scope:** the progression machines, challenges, unlocks, cash and statistics running
identically on every seat from shared facts, the autosave identical on both, the server holding
the blob. Front page: [README](../../README.md). Design: [design](../design.md) §3.2, §3.3, §3.7.

## State (2026-11-10)

Not started. M0 and M1 run each seat's career from its own save; nothing of it is shared. The
analysis for M2 (the career's state, its tick, the autosave's bytes, the tutorial's objectives,
the facts lockstep as a template) is in progress as a research note.

**Planned (from the design):** the round becomes the whole session (type-42 scope, every
console runs every script from every player's facts, the server's seed as `online_random`); the
"the player" ledger (everyone / the one who did it / nearest / each for themself / the server);
completion rules as data (`coop-rules.json`, default tutorials `Everyone`, else `Anyone`).
